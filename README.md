# Diktype — загрузки для Windows

[Скачать Diktype 1.22.5 для Windows x64 — полный установочный комплект, 237 МБ](https://github.com/Rtsmikh/diktype-releases/releases/download/v1.22.5/Diktype-1.22.5-CPU.zip)

Скачивание не требует регистрации или входа в GitHub.

1. Распакуйте архив целиком.
2. Запустите **Diktype-Setup.exe** из распакованной папки. Оба архива компонентов и остальные файлы должны оставаться рядом с EXE.
3. При обновлении сначала завершите запись и закройте Diktype через **«Выйти»** в меню трея.

Условия лицензии доступны в установщике и входят в комплект. Этот репозиторий предназначен для готовых установочных комплектов; история разработки здесь не размещается.
